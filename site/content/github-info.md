### Agentic workflow ideas

Sample workflows from [Awesome Copilot](https://github.com/github/awesome-copilot/tree/main/workflows) to learn from:

- `daily-issues-report`: summarize repository issues each day.
- `weekly-comment-sync`: keep comments in sync on a weekly schedule.
- `ospo-stale-repos` and `ospo-org-health`: spot stale repositories and check organization health.

For more, browse the [GitHub Blog](https://github.blog/latest/) and [Changelog](https://github.blog/changelog/).
